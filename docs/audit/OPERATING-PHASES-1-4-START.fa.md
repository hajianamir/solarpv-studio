# شروع ادامهٔ مسیر محصول سه‌حالته — 2026-11-03

دامنه با انتخاب کاربر: مسیر بهره‌برداری powerplant/ongrid/offgrid، نه فازهای ۴۸–۵۱ پژوهشی PVLIB.

## موجودی پیش از تغییر
- فاز ۱: پذیرش خروجی معتبر سالانه، context و تفکیک screening/operational موجود است.
- فاز ۲: آرشیو، انتقال، گزارش OOXML و PDF واقعی موجود است؛ Safari native import و پایداری تست PDF باز است.
- فاز ۳: دفتر AC، load-first، بهینه‌سازی گسسته، دیزل و مدل calendar/EFC مستقل موجود است؛ این‌ها DC-coupled یا مدل الکتروشیمیایی نیستند.
- CI عمومی: direct-study browser شکست‌های باز دارد؛ تغییرات قبلی و نامرتبط workflow و اسناد پژوهشی در working tree حفظ می‌شوند.

## برنامه و گیت
۱. تشخیص مستقل فایل دیسکی Safari با ورودی حداقلی، مجوز خواندن صریح و ثبت نسخه؛ هیچ تزریق File مصنوعی جای پذیرش native محسوب نمی‌شود.
۲. حذف race در انتظار دانلود و بهبود تشخیص خطای PDF؛ تست production و readback.
۳. بررسی direct-study browser و اصلاح فقط خطای بازتولیدشده؛ تست و exact-SHA CI.
۴. آغاز محدود فاز ۴ نرم‌افزار: مقایسهٔ کنترل‌شدهٔ دو سیاست load-first/optimal-discrete روی همان شواهد و context با hash مشترک، خروجی اختلاف‌ها و بدون تغییر مالی. شروع آن به معنی پذیرش نهایی فازهای قبل یا عبور از blocker بیرونی نیست.

## پژوهش اولیه
جست‌وجوی `Safari safaridriver file upload NotReadableError tmp selenium` یک گزارش ثالث با بازتولید مستقل نشان داد: https://github.com/sohweiyu2023/CosmicTranscriberWeb/issues/6 . این گزارش شاهد رفع یا اثبات علت خطای این مخزن نیست؛ probe مستقل خود مخزن لازم است. رفتار File.text باید با دسترسی فایل واقعی تفکیک شود. موفقیت WebKit معادل Safari بومی نیست.

معیار خاتمه: تست‌های عددی/قرارداد/مرورگر و شواهد دقیق SHA؛ موارد وابسته به پلتفرم یا دادهٔ واقعی صریحاً blocked باقی می‌مانند. هیچ دادهٔ عملیاتی ساخته نمی‌شود.
