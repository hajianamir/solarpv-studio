- گزارش HTML ایستا و قابل چاپ به PDF، با escape و CSP بدون script: خلاصه و مقایسه، ماه‌های UTC، پارامترها، فرض‌ها، warnings، manifest و execution. JSON کامل و CSV میانجی همچنان موجودند.
