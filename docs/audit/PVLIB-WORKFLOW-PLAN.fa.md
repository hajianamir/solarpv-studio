# تکمیل گردش‌کار — پیش از کدنویسی، ۲۰۲۶-۱۱-۰۳

موجودی: worker و API مستقیم موجودند؛ پنل فقط JSON می‌گیرد؛ نتیجه در حافظه است؛ سازنده، کنترل CSV، کتابخانه و مقایسه ندارد. در این مرحله معادله یا مدل فیزیکی جدید اضافه نمی‌شود.

## منابع بررسی‌شده و تصمیم‌ها

- https://pvlib-python.readthedocs.io/en/v0.13.1/user_guide/modeling_topics/timetimezones.html — localize با convert متفاوت است و DST مهم است. CSV باید زمان ISO با offset صریح داشته باشد؛ هیچ حدس timezone یا تبدیل timestamp شروع/میانه به پایان انجام نمی‌دهیم.
- https://pvlib-python.readthedocs.io/en/v0.13.1/reference/generated/pvlib.iotools.read_pvgis_hourly.html — خواندن داده و metadata جداست؛ حتی قرارداد azimuth PVGIS با pvlib فرق دارد. CSV استاندارد این برنامه با ستون‌های واحددار تعریف می‌شود؛ واردکردن فایل خام PVGIS/SAM به‌عنوان داده معادل ممنوع است. دو صفحه فرمت SAM قابل واکشی نبودند؛ ادعای بررسی آنها نمی‌شود.
- https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB — ذخیره async و transaction؛ موفقیت درخواست لزوماً commit تراکنش نیست. نسخه DB، خطای quota/blocked و completion صریح لازم است. ذخیره محلی مرورگر account isolation یا پشتیبان دائمی نیست.

## قرارداد اجرا

سازنده بدون پیش‌فرض تجهیزات/هواشناسی، CSV با ۶ ستون دقیق، گزارش تعداد/بازه/حداقل/حداکثر و خطای ردیف؛ فقط داده معتبر قابل اعمال است. تغییر فرم فوراً نتیجه قبلی را از اجرای مجدد جدا می‌کند. ذخیره snapshot درخواست و نتیجه در IndexedDB با شناسه مستقل، بازیابی بدون اجرای خودکار، حذف صریح و خروجی قابل‌انتقال. نتیجه بازیافتی کاربر-ارائه‌شده تلقی می‌شود، نه امضای اصالت. مقایسه تنها برای سایت، هواشناسی و نسخه/مدل یکسان؛ ظرفیت ممکن است فرق کند و توان نامی نمایش داده می‌شود. گزارش HTML ایستا با escape، ورودی، فرض‌ها، manifest و جدول ماهانه و مقایسه؛ بدون ورود به finance.

## آزمون‌ها

واحد: CSV نقل‌قول، BOM، ردیف خالی/مفقود/تکراری، offset، شکاف، حد حجم، مقایسه ناسازگار و escape گزارش. مرورگر: ساخت از فرم و CSV، اجرای Python، ذخیره، reload/restore، تغییر پارامتر و اجرای سناریو دوم، مقایسه، دانلود گزارش و حذف. آزمون‌های قبلی Python/API/browser و lint/build نیز اجرا می‌شوند.
