# مرحله۵۰ — موجودی و دامنه پیش از کد
تاریخ: 2026-11-03؛ شاخه arena/237e6ea2-solarpv-studio؛ پایه5438fb5. working tree شامل تغییرات قدیمی است و حفظ می‌شود.

موجودی: production worker شامل مدل‌های انرژی و تلفات کابل/ترانس است؛ جایگزینی بی‌مدرک آن مجاز نیست. مراحل۴۸/۴۹ هنوز تأیید عملیاتی ندارند. دادهٔ واقعی topology/ولتاژ/حدود سازنده ارائه نشده است.

مرجع بررسی‌شده پیش از کد: MATPOWER manual بخش4.3.2 Current Summation Method، معادلات4.16–4.19، https://matpower.app/manual/matpower/DistributionPowerFlow.html . دامنه انتخابی: شبکه شعاعی سه‌فاز متعادل، slack ثابت، توان ثابتPQ، امپدانس سری هر فاز با همه ولتاژها ارجاع‌شده به یک سطح. بدون shunt، tap، حلقه، نامتعادلی و کنترل دینامیکی. استفاده از transformer صرفاً به‌صورت امپدانس معادل ارجاع‌شده، نه مدل کامل ترانس.

قرارداد: P/Q مثبت مصرف؛ export منفی توان واردشونده از slack. PF ژنراتور با Q مثبت تزریق صریح؛ export cap روی توان خالص POI با بازحل تلفات و کاهش متناسب همه ژنراتورها، PF ثابت. Q load مستقل باقی می‌ماند. کسر دوباره تلفات در waterfall ممنوع؛ خروجی فقط snapshotW، نه انرژی یا ایمنی. حل شکست‌خورده fallback ندارد. محدودیت convergence/voltage/تعدادگره و iteration صریح.

پیش از ادغام عملیاتی، تأیید دامنه توسط مهندس، topology و مدارک سازنده لازم است؛ اکنون فقط پژوهشی conditional. ampacity/protection محاسبه/تأیید نمی‌شود. تست برنامه‌ریزی‌شده: oracle تحلیلی مدار۲گره، root مستقل معادلات چندگره، balanceP/Q/I²R، PF، signed import/export، cap با بازحل و عدم doublecount، رد توپولوژی/ورودی غلط و عدم همگرایی؛ regressionهای قبلی.
