# به‌روزرسانی وابستگی‌های منسوخ

## دامنه و تصمیم

این اصلاح برای حذف چهار هشدار نصب دربارهٔ `rimraf@2`، `fstream@1`، `lodash.isequal@4` و `eslint@9` است. محاسبات، schema پروژه، قرارداد مالی و پذیرش انرژی پژوهشی تغییر نمی‌کنند.

ExcelJS فعلاً آخرین نسخهٔ منتشرشدهٔ 4.4.0 است، اما وابستگی‌های قدیمی آن منشأ سه هشدار بودند. برای حفظ API و قالب خروجی فعلی، به‌جای تعویض کامل کتابخانه، override فقط در زیرشاخهٔ ExcelJS اعمال می‌شود:

- `fast-csv` → **5.0.8**؛ وابستگی منسوخ `lodash.isequal` دیگر لازم نیست.
- `unzipper` → **0.12.5**؛ زنجیرهٔ `fstream → rimraf@2` حذف می‌شود.
- `eslint` → **10.15.0** و `eslint-plugin-react-hooks` → **7.1.1** با peer dependency سازگار.

این overrideها فراتر از بازهٔ اعلام‌شدهٔ ExcelJS هستند؛ تضمین بالادستی برای این ترکیب ادعا نمی‌شود. سازگاری مسیرهای مصرف‌شده با تست واقعی CSV و XLSX سنجیده می‌شود. نسخه‌ها برای بازتولیدپذیری دقیق قفل شده‌اند؛ هنگام انتشار نسخهٔ جدید ExcelJS باید نیاز به override دوباره بررسی شود.

نسخهٔ جدید plugin شامل قواعد جدید React Compiler است. چون این پروژه مهاجرت به Compiler را انجام نداده، قرارداد قبلی lint صریحاً حفظ شده است: `rules-of-hooks` و `exhaustive-deps` هر دو error هستند. قواعد قبلی خاموش یا ضعیف نشده‌اند؛ قواعد اضافی Compiler خودکار فعال نمی‌شوند.

## راهنمای نصب

Node.js LTS فعلی (ترجیحاً 24 یا جدیدتر) را نصب کنید. شرط فنی بسته و ESLint اکنون `^20.19.0 || ^22.13.0 || >=24` است؛ این شرط به‌تنهایی تضمین پشتیبانی امنیتی همهٔ نسخه‌های قدیمی Node نیست. `install.bat`، `start.bat` و launcher مشترکاً همین شرط را بررسی می‌کنند و در نسخهٔ ناسازگار پیش از نصب/اجرا متوقف می‌شوند.

- ویندوز: `install.bat` را دوباره اجرا کنید؛ سپس `start.bat`.
- سایر سیستم‌ها: `npm ci` با lockfile جدید.
- فایل `.env` و پروژه‌های کاربر حذف یا بازنویسی نمی‌شوند.
- از `npm audit fix --force` یا مخفی‌کردن هشدارهای npm برای این اصلاح استفاده نشده است.

## پذیرش و بازآزمایی

```sh
npm ci
npm run test:dependencies
npm run verify:exports
npm run lint
npm run build
npm test
npx tsx scripts/test-browser-regressions.ts
npm audit
```

`test:dependencies` موارد زیر را بررسی می‌کند:

1. حدود مجاز/غیرمجاز نسخهٔ Node و استفادهٔ installer/launcher از preflight؛ حفظ repair و مسیرهای دارای فاصله.
2. CSV فارسی/Unicode، comma، quote و newline، اعداد مثبت/منفی و صفر، رد CSV معیوب.
3. نوشتن و خواندن streaming XLSX از مسیر واقعی `unzipper` و خواندن معمولی XLSX.
4. نبود هیچ ورودی deprecated در lockfile و حذف سه وابستگی غیرمستقیم منسوخ.

`verify:exports` محتوای واقعی خروجی DOCX/XLSX/JSON، منشأ و بازورود پروژه را می‌خواند؛ benchmarkها رگرسیون محاسبات قبلی را بررسی می‌کنند. آزمایش‌ها صحت فیزیکی جدید یا دقت مالی جدیدی ادعا نمی‌کنند. lint هنوز هشدارهای موجود `no-explicit-any` دارد؛ این‌ها هشدار npm دربارهٔ بستهٔ منسوخ نیستند. تست بومی Windows/macOS در این محیط Linux انجام نشده است. تمام حالت‌های اختیاری ExcelJS، به‌ویژه تمام ترکیب‌های ZIP و CSV، ادعای پوشش کامل ندارند.

## rollback

تغییرات این اصلاح در package/lockfile، ESLint config، شرط Node در installer/launcher و تست‌ها/مستندات مرتبط را با هم بازگردانید و `npm ci` اجرا کنید. مهاجرت داده یا بازگردانی schema لازم نیست. rollback به lockfile قبلی هشدارهای منسوخ‌شدن را نیز برمی‌گرداند. feature flag زمان اجرا برای وابستگی‌های زمان نصب وجود ندارد.

## نتیجهٔ اجرای این تغییر

در محیط Linux با Node 22.22.3، نصب تمیز بدون هشدار منسوخ‌شدن، audit با صفر آسیب‌پذیری، تست وابستگی‌ها، بازخوانی خروجی‌ها، lint/TypeScript، build، benchmarkها و رگرسیون Chromium همگی موفق بودند. lint دارای ۹۳ هشدار موجود و صفر خطاست. پیام‌های ERR_FAILED در رگرسیون مرورگر مربوط به مسدودسازی عمدی درخواست‌های خارجی‌اند؛ گیت نهایی suite موفق است. CI برای اجرای تست سازگاری وابستگی‌ها و ماتریس Node 20/22/24 تنظیم شده، اما نتیجهٔ اجرای ریموت CI در این رسید ادعا نمی‌شود. رسید فایل‌ها و نتایج: `docs/audit/DEPENDENCY-MODERNIZATION-GATE.json`.
