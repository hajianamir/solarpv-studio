# ADR-010: Tracker Backtracking Engine & pvlib Cross-Validation Fixtures

**Status:** Accepted
**Date:** 2026-11-03

## Context
PR-2a-7 replaces the hardcoded tracker placeholders (+26.5% transposition,
-1.2% near-shading) in `waterfallLossEngine.ts` with a real single-axis
tracker model with slope-aware backtracking.

## Decision
- Engine: `src/engine/tracker/backtrackingEngine.ts` — a pure, deterministic
  TypeScript port of **pvlib 0.16.1** `tracking.singleaxis` /
  `shading.projected_solar_zenith_angle` (Marion & Dobos NREL/TP-6A20-58891;
  Anderson & Mikofski NREL/TP-5K00-76626) plus `irradiance.get_total_irradiance`
  with the isotropic sky model.
- Reference fixtures: generated by `scripts/generate-pvlib-fixtures.py`
  (Python 3.11.2, pvlib 0.16.1, numpy/pandas from PyPI) and committed as
  `src/engine/core/benchmarks/trackerFixtures.ts`:
  - 60 point fixtures (5 sites x 4 seasonal dates x 3 solar times,
    GCR=0.33, axis_tilt=0, max_angle=60)
  - 16 slope fixtures (axis_tilt = +/-5 deg)
  - 5 annual representative-day fixtures (12 days x 24 h clear-sky via
    pvlib `clearsky.ineichen`, scaled x365/12)
- NREL SAM itself is not runnable in this sandbox; the annual reference is
  pvlib's clear-sky representative-day model (the same reference
  implementation family SAM/pvlib uses), with the exact regeneration
  procedure documented in the generator script. Regenerate with:
  `python3 scripts/generate-pvlib-fixtures.py`

## Verification
- `[TRACKER-PVLIB]`: 76 fixtures, max rotation error 0.0000 deg, max POA
  relative error 0.000% (tolerances: 0.5 deg / 0.5%)
- `[TRACKER-PVLIB-ANNUAL]`: 5 sites annual POA vs pvlib, max error 0.000% (tolerance 0.3%). **NOTE**: This is pvlib cross-validation, NOT NREL SAM independence. SAM validation is deferred to `PR-2a-7-SAM-VALIDATION`. The annual method uses 288 representative-day points scaled x365/12 on both the pvlib fixture generator and the TS test.
- `[TRACKER-PHYSICS]`, `[TRACKER-SLOPE]`, `[TRACKER-WATERFALL]`,
  `[TRACKER-DETERMINISM]`: all PASS; 93/93 total tests PASS.
